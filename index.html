Puntos de integración de API

Esta beta usa datos simulados. Así se conectarían las APIs reales para producción:
API #1Autenticación Telegram
Validar el initData que Telegram envía al abrir la Mini App (firma HMAC con el token del bot) para confirmar la identidad del usuario sin pedir login manual.
→ backend/auth/validateInitData.js
API #2Pasarela de pagos crypto
Depósitos, retiros y saldo real vía proveedor de wallet crypto (custodial o no-custodial). Reemplaza el saldo simulado y los botones "Depositar / Retirar".
→ backend/payments/cryptoGateway.js
API #3Proveedor de juegos
Motor de juego / RNG certificado que procesa apuestas y resultados. Sustituye las tarjetas de juego mock por el iframe o SDK del proveedor.
→ backend/games/gameProvider.js
API #4KYC / AML
Verificación de identidad y monitoreo de transacciones según la jurisdicción con licencia. Se activa en el flujo de registro y antes de retiros grandes.
→ backend/compliance/kycProvider.js
API #5Notificaciones (Bot API)
El bot de Telegram envía mensajes push al usuario: depósito confirmado, premio ganado, retiro procesado. Usa el token del bot vía Bot API.
→ backend/bot/notifications.js
